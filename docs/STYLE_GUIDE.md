# Nuro style guide
Colors: stage #ABABB1 (hero), ink #1B1B1F (text, dark cards), steel #B4B4BC (muted headline), fleet #222222, white.
Type: Headings/display = Stack Sans Notch (SemiBold 600 for titles, Bold 700 for AUTONOMY / NURO / OUR FLEET / 35%). Body, buttons, labels, card titles = Inter. Tracking -0.04em, leading 0.9 on giant words. Body 16-20px, max 70ch.
Radius: cards 16px, pills full. Easing: cubic-bezier(.22,1,.36,1) (ease-nuro) for UI, GSAP power4.out for entrances.
Motion: one orchestrated entrance per section; hover/scroll motion must respond to input; honor prefers-reduced-motion.
